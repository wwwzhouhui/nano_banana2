# Privacy Policy

This plugin processes your text prompts to generate images using the Juxin API. Here's how your data is handled:

## Data Processing

- **Text Prompts**: Your text content is sent to the Juxin API service to generate corresponding images
- **API Communication**: The plugin communicates with Juxin servers (https://api.jxincm.cn) to process text-to-image requests
- **Generated Images**: Image files are temporarily downloaded and processed by the plugin, then returned to your workflow
- **Model**: Uses Gemini 3 Pro Image Preview model for high-quality image generation

## Data Storage

- **No Local Storage**: The plugin does not permanently store your text prompts or generated images locally
- **Temporary Processing**: All data processing is temporary and happens only during the image generation process
- **API Key Security**: Your Juxin API key is stored securely within your environment and is not logged or transmitted elsewhere

## Third-Party Services

- **Juxin API**: Your text prompts are sent to the Juxin image generation service to create images
- **Network Communication**: The plugin requires internet connectivity to communicate with Juxin servers
- **Service Provider**: Juxin API service (https://api.jxincm.cn) processes your requests according to their privacy policy
- **AI Model**: Requests are processed using Google's Gemini 3 Pro Image Preview model through Juxin API

## Optional Features

- **Negative Prompts**: You can specify content you don't want in images to improve generation quality
- **Aspect Ratio Selection**: Choose from various aspect ratios (1:1, 16:9, 9:16, 4:3, 3:4)
- **Style Control**: Select from different artistic styles (realistic, anime, oil-painting, watercolor, sketch)
- **Batch Generation**: Generate 1-4 images at once

## Data Retention

- The plugin does not retain any user data after task completion
- Generated images are temporarily processed and immediately returned to your workflow
- No persistent storage of prompts, images, or user information within the plugin

## Data Transmission

- Text prompts and configuration parameters are transmitted securely over HTTPS to Juxin API
- Generated images are returned securely over HTTPS
- No data is shared with any other third parties beyond the Juxin service

## Your Rights

- You control what prompts you send to the service
- You can stop using the plugin at any time
- Generated images belong to you according to Juxin API's terms of service

For more information about how Juxin API handles your data, please refer to their privacy policy at https://api.jxincm.cn
